# Church & Religion Landing Pages Collection

A complete, pixel-crafted collection of **13 responsive landing pages** for church, worship, festival, and faith-based community initiatives.

Built with **pure HTML5 + Tailwind CSS (via CDN) + Font Awesome 6 + Vanilla JS**. No Node/build-step required—open any `index.html` file directly in any modern browser.

## ✨ Features & Architecture Rules

1. **100% Free Stock Photography**: All imagery is sourced from high-resolution, royalty-free stock (Unsplash).
2. **Mobile First & Fully Responsive**:
   - Clean navigation on desktop.
   - Slide-in side drawer navigation menu on mobile/tablet via hamburger icon.
3. **Interactive Elements (No Dead Links)**:
   - **Read More / See More Modals**: Rich dialogs displaying complete articles, dates, categories, and scriptures.
   - **Video Modals**: Responsive 16:9 modal video player for sermons and live streams.
   - **Interactive Donation & Ticketing**: Preset amounts, custom input, and visual feedback toasts.
   - **Keyboard & Touch Accessibility**: `Escape` key and backdrop click immediately dismiss active modals/drawers.
4. **No Cart / Shop Icons**: Clean, focused interface geared purely towards worship, ministry, and community outreach.

- **Mudah Dilepas Saat Klien Membeli**:
  - **Opsi 1 (Instan tanpa edit HTML)**: Buka `paywall.js` di folder terkait, ganti `enabled: true` menjadi `enabled: false`.
  - **Opsi 2 (Hapus Permanen)**: Hapus file `paywall.js` dan hapus baris `<script src="paywall.js"></script>` dari `index.html`.

## 🚀 Getting Started

Simply clone this repository and open any of the folders:

```bash
git clone https://github.com/rizoadev/church-landing-pages.git
cd church-landing-pages

# Open any landing page directly in your browser:
# Example:
open 01-events-home-chapel/index.html
# or with python local server:
python3 -m http.server 8000
```
