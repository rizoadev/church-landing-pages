# Koleksi 13 Landing Page Gereja Nusantara (Indonesia)

Koleksi lengkap **13 landing page responsif** untuk gereja dan komunitas kristiani di Indonesia, diadaptasi dengan **data riil, sejarah, lokasi, nomor kontak, jadwal liturgi/ibadah, serta pelayanan diakonia nyata** yang mewakili berbagai denominasi dan wilayah dari Sabang sampai Merauke.

Dibangun menggunakan **HTML5 murni + Tailwind CSS (via CDN) + Font Awesome 6 + Vanilla JS**. Ringan, tanpa build-step, langsung jalan di browser apapun!

🌐 **Live Production (Cloudflare Pages)**: [https://church-landing-pages.pages.dev](https://church-landing-pages.pages.dev)  
📦 **GitHub Repository**: [https://github.com/rizoadev/church-landing-pages](https://github.com/rizoadev/church-landing-pages)

## ✨ Fitur & Standar Arsitektur

1. **100% Free Stock Photography**: Seluruh gambar menggunakan foto beresolusi tinggi dan bebas royalti dari Unsplash.
2. **Mobile First & Fully Responsive**: Navigasi desktop elegan, mobile burger menu dengan slide-in side drawer lengkap.
3. **Fungsionalitas Interaktif Tanpa Dead-Link**:
   - **Modal Artikel & Warta Lengkap**: Membuka modal detail berita, ayat Alkitab, dan jadwal kegiatan.
   - **Modal Video & Audio**: Pemutar video misa/khotbah dan audio streaming renungan/mazmur.
   - **Modal Donasi & Tiket Ibadah**: Pilihan nominal, formulir jemaat, dan konfirmasi toast.
   - **A11y**: Tombol `Escape` (ESC) & klik luar modal langsung menutup popup.
4. **Tanpa Icon Shop / Cart**: Antarmuka bersih, sakral, dan murni berorientasi pada peribadahan dan pelayanan sesama.
5. **Paywall Preview 45 Detik**: Proteksi pratinjau otomatis aktif setelah 45 detik dengan CTA WhatsApp ke **+62 878-8127-2246** (mudah dilepas via konfigurasi `enabled: false`).
